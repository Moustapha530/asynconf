# Asynconf

A mobile app for Asyncof Salon.

## Description

Asynconf is a salon management app designed to help salon owners and staff manage appointments, services, and client information more efficiently.

## Features

- Book and manage salon appointments
- Track services offered and pricing
- Store client details and visit history
- Improve salon workflow and customer experience

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio.
3. Build and run the app on an Android device or emulator.
